# Lecture 1: Image Classification with Linear Classifiers

## 图像分类的挑战

对于计算机来说，图像是一个矩阵。每个元素是一个像素值，通常是一个 `0-255` 之间的整数，表示该像素的亮度或颜色信息。对于彩色图像，每个像素可能包含多个通道（如RGB），每个通道都有自己的像素值。因此，图像可以被表示为一个高维的向量。

**例如：** 一个 `32x32` 的 RGB 图像可以被表示为一个 $32 \times 32 \times 3 = 3072$ 维的向量。

进行图像分类时，我们需要应对以下主要挑战：

1. **Viewpoint variation（视角变化）**：同一对象在不同的视角下可能看起来完全不同。
2. **Scale variation（尺度变化）**：同一对象在不同的距离下可能看起来大小不同。
3. **Occlusion（遮挡）**：对象可能被其他物体部分遮挡。
4. **Deformation（形变）**：同一对象可能具有不同的形状或姿态。
5. **Intra-class variation（类内差异）**：同一类别的对象可能具有不同的外观。
6. **Background clutter（背景杂乱）**：对象可能出现在复杂的背景中。
7. **Low resolution（低分辨率）**：图像可能具有较低的分辨率。

---

## 数据驱动的方法 (Data-Driven Approach)

由于硬编码算法无法应对复杂的图像分类任务，我们采用**数据驱动算法**，通过从大量的图像数据中学习来进行分类。

**基本流程：**

1. **收集数据**：收集一个包含对应标签和图片的数据集。
2. **训练分类器**：用机器学习的方法（如线性分类器等）训练一个模型。
3. **预测与评估**：使用训练好的分类器对新的未见图像进行分类。

> 线性分类器的基本思想是将图像表示为高维向量，并试图找到一个（或多个）超平面，在空间中将不同类别的图像分开。

---

## 评分函数 (Score Function)

线性分类器的核心是一个**评分函数**，它将输入图像的像素值映射为每个类别的置信度分数：

$$ f(x_i, W, b) = W x_i + b $$

其中：
- $x_i$ 是第 $i$ 张图像展平后的列向量，维度为 $D$（如 3072）
- $W$ 是权重矩阵，维度为 $K \times D$（$K$ 为类别数）
- $b$ 是偏置向量，维度为 $K$
- 输出是一个 $K$ 维向量，每个元素表示该图像属于对应类别的得分

---

## Nearest Neighbor Classifier（最近邻分类器）

**最近邻分类器**是一种最基础的分类方法。本质上就是拿着测试图片和训练集中的每一张图片进行比较，找到距离最近的那一张图片，然后把它的标签作为预测结果。

- **优点**：逻辑易懂，训练速度极快（只需记录数据）。
- **缺点**：测试阶段**计算量极大**（尤其在训练集很大时），因为需要跟每一张训练图像计算距离。

### 距离的计算方式

**1. 曼哈顿距离 (L1 Distance)**

计算所有对应像素差值的绝对值之和：

$$ d_1(x, y) = \sum_{i} |x_i - y_i| $$

**2. 欧氏距离 (L2 Distance)**

计算对应像素差值的平方和的平方根：

$$ d_2(x, y) = \sqrt{\sum_{i} (x_i - y_i)^2} $$

> **对比**：欧式距离在某些情况下更适合，特别是需要考虑不同维度组合时的真实距离，但计算量往往由于平方及开方操作相比 L1 有所增加。

### 代码实现演示 (使用 L1 距离)

```python
import numpy as np

# 假设 load_CIFAR10 函数负责读取数据集
Xtr, Ytr, Xte, Yte = load_CIFAR10('cifar-10-batches-py')

# 数据解析：
# - Xtr: 50000 x 32 x 32 x 3 的数组 (训练集：50000张 32x32 的 RGB 图片)
# - Ytr: 长度为 50000 的一维数组 (训练集标签)
# - Xte: 10000 x 32 x 32 x 3 的数组 (测试集)
# - Yte: 长度为 10000 的一维数组 (测试集标签)

# 为了计算方便，将图片展平为行向量，Xte_rows 是 10000 x 3072 的二维数组
Xte_rows = Xte.reshape(Xte.shape[0], 32 * 32 * 3)
Xtr_rows = Xtr.reshape(Xtr.shape[0], 32 * 32 * 3)

# 注：shape 会返回数组维度元组。Xtr.shape[0] 返回 50000。
# Xtr.reshape(50000, 3072) 会将原来的数据拉平。

class NearestNeighbor(object):
    def train(self, X, Y):
        # 训练阶段仅仅保存所有的训练数据和标签，时间复杂度 O(1)
        self.Xtr = X
        self.Ytr = Y

    def predict(self, X):
        # 创建一个长度等于测试集总样本数的零数组，用来存储预测标签
        Yte_predict = np.zeros(X.shape[0], dtype=self.Ytr.dtype)

        for i in range(X.shape[0]):
            # 核心：计算当前测试样本与所有训练样本的 L1 距离
            # 注意 X[i] 广播计算时最好与 self.Xtr 保持维度匹配
            distances = np.sum(np.abs(self.Xtr - X[i, :]), axis=1)

            # 找到距离最小的那一个样本的索引
            min_index = np.argmin(distances)
            # 通过索引拿出它真实的标签作为该图像预测结果
            Yte_predict[i] = self.Ytr[min_index]
        return Yte_predict

# --- 使用举例 ---
nn = NearestNeighbor()             # 创建分类器实例
nn.train(Xtr_rows, Ytr)            # 传入预处理好的训练集进行"训练"
Yte_predict = nn.predict(Xte_rows) # 对测试数据进行推理预测

print('accuracy: %f' % (np.mean(Yte_predict == Yte))) # 计算正确率
```

> **代码解析与思考**：`predict` 方法中使用循环实时计算距离，导致算法出现"**训练快，测试慢**"的特性。而在工程实践中，我们希望的往往是"训练可以慢很久，但部署后的测试推理必须快"。

## k-Nearest Neighbor Classifier（K-最近邻分类器，k-NN）

**k-最近邻分类器**是最近邻分类器的优化扩展。

在预测时，我们依然计算新图像与训练集中每个图像的距离，但不只看最近的那一个，而是找到距离最近的 **$k$** 个图像。然后，这 $k$ 个图像会根据自己所属类别进行**投票 (多数表决)**，出现次数最多的类别将作为最终的预测结果。

- **$k$ 值的选择（Hyperparameter 超参数）**：
  - **较小的 $k$（如 $k=1$，即最近邻分类器）**：模型非常贴合训练数据中的孤立点，容易拟合到噪声上，导致**过拟合 (Overfitting)**。
  - **较大的 $k$**：能使得分类决策边界更为平滑，起到了部分抗噪作用。但设置过大时容易造成**欠拟合 (Underfitting)**。
  - **调参方式**：通常通过**验证集 (Validation set)** 或者 **交叉验证 (Cross-Validation)** 来挑选出表现最好的 $k$ 值。

### 方法一：使用验证集调参

```python
Xval_rows = Xtr_rows[:1000, :]  # 从训练集中取出前1000个样本作为验证集
Yval = Ytr[:1000]               # 验证集对应的标签
Xtr_rows = Xtr_rows[1000:, :]   # 剩余的样本作为新的训练集
Ytr = Ytr[1000:]
validation_accuracies = []

for k in [1, 3, 5, 8, 10, 20, 30, 50, 70, 100]:
    nn = NearestNeighbor()
    nn.train(Xtr_rows, Ytr)      # 训练分类器
    Yval_predict = nn.predict(Xval_rows)  # 对验证集进行预测
    acc = np.mean(Yval_predict == Yval)    # 计算准确率
    print('k=%d, accuracy: %f' % (k, acc))
    validation_accuracies.append((k, acc))

# 这样就可以找出结果最好的 k 值了
```

### 方法二：交叉验证 (Cross-Validation)

将训练集划分成多个子集（folds），每次用其中一个子集作为验证集，其他子集作为训练集，重复多次，最后取平均准确率最高的 $k$ 值。

### KNN 实际应用时的预处理

1. **归一化**：将特征缩放到统一范围
2. **降维**：使用 PCA 等方法减少计算量
3. **在验证集上调参**：选择合适的 $k$ 值

KNN 的优点是简单易懂，缺点是计算量大，尤其是在训练集很大时，因为每次预测都需要计算与所有训练样本的距离。

## 线性分类器 (Linear Classifier)

线性分类器的评分函数为 $f(x_i, W, b) = W x_i + b$，可以从以下三个角度理解：

**理解角度 1 — 分类器组合**：$W$ 是所有分类器的组合，参数矩阵 $W$ 的每一行对应一个分类器，每一列对应一个像素点。对于输入图像 $x$，计算 $Wx$ 得到一个长度为类别数的向量，每个元素表示该图像属于对应类别的得分。最终预测类别是得分最高的那个。

**理解角度 2 — 模板匹配**：将线性分类器看作模板匹配，$W$ 的每一行是一个模板（即该类别的"原型图像"），$Wx$ 的结果表示输入图像与每个模板的匹配程度（内积越大越相似）。预测类别就是与哪个模板匹配程度最高。

**理解角度 3 — 高维空间中的超平面**：将图像看作高维空间的点，线性分类器就是在高维空间中寻找一个超平面来分割不同类别的点。$W$ 矩阵定义了这个超平面的位置和方向。预测时，输入图像 $x$ 通过与 $W$ 的乘积计算出它在这个高维空间中的位置，从而判断它属于哪个类别。

> **模板是哪里来的？** 线性分类器的模板是通过训练过程学习得到的。训练过程中，模型会调整权重矩阵 $W$，使得对于训练数据，正确类别的得分更高，错误类别的得分更低。最终，$W$ 中的每一行就形成了一个模板，代表了该类别的特征模式。

**和 KNN 的区别**：KNN 是基于距离的分类方法，而线性分类器是基于权重矩阵的线性组合来进行分类。KNN 需要计算与所有训练样本的距离，而线性分类器只需要计算一次矩阵乘法。

### 偏置项和权重合并

在实际实现中，我们通常会将偏置项和权重合并到一个矩阵中，以简化计算。具体做法是将输入图像 $x$ 扩展为一个新的向量 $x'$，在原有的像素值后面添加一个常数 1（代表偏置项）。同时，将权重矩阵 $W$ 扩展为 $W'$，在原有的权重矩阵 $W$ 的最后一列添加一列偏置权重。这样，计算 $Wx + b$ 就可以直接计算 $W'x'$，同时考虑了权重和偏置的影响。这种方法不仅简化了代码实现，还使得模型更容易进行训练和优化。

### 图像数据预处理

在送入线性分类器之前，通常需要对图像数据进行预处理：

1. **归一化 (Normalization)**：将像素值缩放到一个特定的范围（如 $[0, 1]$ 或 $[-1, 1]$），以减少不同特征之间的量级差异。
2. **零中心化 (Mean Subtraction)**：减去整个训练集的均值，使数据以零为中心，有助于梯度下降的收敛。

# Lecture 2: 损失函数与最优化

## 损失函数 (Loss Function)

损失函数是用来衡量模型预测结果与真实标签之间差距的函数。对于 $N$ 个训练样本 $\{(x_i, y_i)\}_{i=1}^N$，损失函数常写为：

$$ L = \frac{1}{N} \sum_{i=1}^{N} L_i(f(x_i, W), y_i) $$

其中 $f(x_i, W)$ 是模型对输入 $x_i$ 的预测结果（得分向量），$y_i$ 是真实标签，$L_i$ 是单个样本的损失，用来计算预测结果与真实标签之间的差距。

---

### 1. 多类支持向量机损失函数 (Multiclass SVM Loss)

对于第 $i$ 个数据 $(x_i, y_i)$，通过评分函数 $f(x_i, W)$ 算出不同类别的分值，将所有分值存到向量 $s$ 中（$s = W x_i$）。第 $i$ 个数据的 SVM 损失函数为：

$$ L_i = \sum_{j \neq y_i} \max(0, s_j - s_{y_i} + \Delta) $$

其中：
- $s_{y_i}$ 是正确类别的分值
- $s_j$ 是其他类别 $j$ 的分值
- $\Delta$ 是一个**边距 (margin)**，表示正确类别的分值应该比其他类别的分值至少大 $\Delta$（通常取 $\Delta = 1$）

> $\Delta$ 的值可以不是 1，可以是其他值，甚至是一个与数据相关的函数。但在实践中通常取 1，因为 $W$ 的缩放可以等价地改变 margin 的效果。

**合页损失 (Hinge Loss)**：$\max(0, -)$ 形式。还有一种变体是**平方合页损失 (Squared Hinge Loss)**：$\max(0, -)^2$，对违反边距的惩罚更重。

#### 代码实现（非向量化版本）

```python
def svm_loss_naive(x, y, W, delta=1.0):
    """
    x: 单张图像展平后的向量，shape (D,)
    y: 真实标签（整数索引）
    W: 权重矩阵，shape (D, C)，C 为类别数
    返回: 该样本的 SVM loss
    """
    scores = x.dot(W)                    # shape (C,), 每个类别的得分
    correct_class_score = scores[y]      # 正确类别的得分
    num_classes = W.shape[1]             # 类别数
    loss_i = 0.0
    for j in range(num_classes):
        if j == y:
            continue
        loss_i += max(0, scores[j] - correct_class_score + delta)
    return loss_i
```

---

### 2. 正则化损失 (Regularization Loss)

> **为什么要加正则化损失？** 因为在训练过程中，如果模型过于复杂，可能会过拟合训练数据，导致在测试数据上的表现不佳。通过添加正则化损失，我们可以限制模型的复杂度，使其更好地泛化到未见过的数据上。正则化项会惩罚权重矩阵 $W$ 中的大权重值，从而鼓励模型学习到更简单的模式，减少过拟合的风险。
>
> **举例**：如果输入向量是 $[1, 1, 1, 1]$，两个权重向量 $w_1 = [1, 0, 0, 0]$ 和 $w_2 = [0.25, 0.25, 0.25, 0.25]$ 都能得到相同的输出（内积都是 1），但 $w_1$ 只依赖一个特征，更容易被该特征中的噪声影响而出现过拟合；$w_2$ 分散了权重，利用了所有特征，泛化能力更强。

常见的正则化形式：

- **L2 正则化**：$R(W) = \sum_k \sum_l W_{k,l}^2$，惩罚大权重，鼓励权重分散
- **L1 正则化**：$R(W) = \sum_k \sum_l |W_{k,l}|$，产生稀疏的权重矩阵，有助于特征选择

正则化强度由超参数 $\lambda$ 控制，最终的损失函数为：

$$ L = \frac{1}{N} \sum_{i=1}^{N} L_i + \lambda R(W) $$

---

### 3. 多类 SVM 损失的完整表达式

$$ L = \frac{1}{N} \sum_{i=1}^{N} \sum_{j \neq y_i} \max(0, s_j - s_{y_i} + \Delta) + \lambda \sum_k \sum_l W_{k,l}^2 $$

其中 $s = f(x_i, W) = W x_i$（这里省略了偏置项 $b$）。

---

### 4. Softmax 损失函数 (Softmax Loss / Cross-Entropy Loss)

Softmax 损失函数是另一种常用的损失函数，特别适用于多类分类问题。它将模型的输出分数转换为概率分布，并计算预测类别与真实类别之间的交叉熵损失。

**步骤一：将得分转为概率（Softmax 函数）**

$$ P(Y = k \mid X = x_i) = \frac{e^{s_k}}{\sum_j e^{s_j}} $$

其中 $s_k$ 是第 $k$ 类的得分。Softmax 函数确保输出是一个合法的概率分布（和为 1，每项非负）。

**步骤二：计算交叉熵损失**

$$ L_i = -\log P(Y = y_i \mid X = x_i) = -\log\left(\frac{e^{s_{y_i}}}{\sum_j e^{s_j}}\right) $$

即我们希望正确类别的概率尽可能大（接近 1），等价于最小化其负对数似然（**最大化对数似然 = 最小化交叉熵损失**）。

**完整表达式（含正则化）：**

$$ L = \frac{1}{N} \sum_{i=1}^{N} -\log\left(\frac{e^{s_{y_i}}}{\sum_j e^{s_j}}\right) + \lambda \sum_k \sum_l W_{k,l}^2 $$

#### 数值稳定性处理

实际计算中，由于指数运算可能导致数值溢出（$e^{s_j}$ 可能非常大），我们通常会对分数进行归一化处理：

$$ \frac{e^{s_k}}{\sum_j e^{s_j}} = \frac{e^{s_k - C}}{\sum_j e^{s_j - C}} $$

其中 $C$ 是一个常数，通常取 $C = \max_j(s_j)$（当前输入的最大分数）。减去 $C$ 不会改变概率分布的结果，但可以确保所有指数项不会过大，从而保持数值稳定。

---

### 5. SVM vs Softmax 对比

| 特性 | SVM (Hinge Loss) | Softmax (Cross-Entropy) |
|------|-------------------|--------------------------|
| 输出含义 | 类别得分（无概率意义） | 类别概率分布 |
| 优化目标 | 正确类比错误类得分高出一个 margin | 正确类的概率尽可能接近 1 |
| 对分数的敏感度 | 一旦满足 margin，不再关心具体数值 | 始终追求更高的正确类概率 |
| 适用场景 | 线性可分数据 | 多类分类，尤其类别有重叠时 |

## 最优化 (Optimization)

最优化（优化）的目标是找到使损失函数最小化的权重矩阵 $W$。

### 1. 随机搜索 (Random Search)

在参数空间中随机采样不同的 $W$，计算损失并保留损失最小的 $W$。这种方法虽然简单直观，但在高维空间中效率极低，几乎不可能找到好的解。

### 2. 梯度下降 (Gradient Descent)

通过计算损失函数关于模型参数的**梯度**，沿着梯度的**反方向**更新参数，以最小化损失函数：

$$ W \leftarrow W - \eta \cdot \nabla_W L $$

其中 $\eta$（learning rate，学习率）是一个超参数，控制每次更新的步长。

> **注意**：我们是向梯度**负方向**更新参数，因为梯度指向损失函数上升最快的方向，我们要最小化损失，所以沿反方向走。

常见的梯度下降变体：
- **批量梯度下降 (Batch GD)**：每次使用全部训练数据计算梯度
- **随机梯度下降 (SGD)**：每次使用一个样本计算梯度
- **小批量梯度下降 (Mini-batch GD)**：每次使用一小批数据计算梯度（实践中**最常用**）

### 3. 数值梯度 (Numerical Gradient)

通过数值方法近似计算梯度，通常使用**中心差分公式**：

$$ f'(x) \approx \frac{f(x + h) - f(x - h)}{2h} $$

其中 $h$ 是一个很小的数值（如 $10^{-5}$）。

数值梯度计算简单、不易出错，但效率极低（每个参数需要两次前向计算），适用于**验证解析梯度的正确性**（梯度检查）。

### 4. 解析梯度 (Analytical Gradient)

通过对损失函数直接求导，得到梯度的解析表达式。这种方法效率远高于数值梯度，是实际训练中使用的方法，但推导容易出错，需要配合梯度检查来验证。

**SVM 损失的梯度（对 $W$）：**

对于单个样本 $(x_i, y_i)$：

$$ \nabla_{W} L_i = \sum_{j \neq y_i} \mathbb{1}[s_j - s_{y_i} + \Delta > 0] \cdot (\text{对 } w_j \text{ 加 } x_i, \text{ 对 } w_{y_i} \text{ 减 } x_i) $$

**Softmax 损失的梯度（对 $W$）：**

$$ \nabla_{W} L_i = x_i \cdot \left( P(Y = k \mid X = x_i) - \mathbb{1}[k = y_i] \right)_{k=1}^{K} $$

即梯度等于"预测概率 - 真实分布（one-hot）"，然后与输入 $x_i$ 做外积。

### 5. 学习率 (Learning Rate)

学习率 $\eta$ 是控制每次参数更新步长的超参数。选择合适的学习率非常重要：

- **过大**：可能导致训练发散，损失震荡甚至越来越大
- **过小**：训练收敛过慢，可能陷入局部最优

### 6. 动量 (Momentum)

动量是一种加速梯度下降的方法，通过引入一个动量项来累积之前的梯度，从而在优化过程中保持一定的惯性：

$$ v \leftarrow \mu \cdot v - \eta \cdot \nabla_W L $$
$$ W \leftarrow W + v $$

其中 $v$ 是速度（动量项），$\mu$ 是动量系数（通常取 0.5 ~ 0.99）。动量可以帮助：
- 加速收敛（尤其在梯度方向一致的维度上）
- 在遇到局部最优或鞍点时更容易跳出

### 7. 自适应学习率方法

这些方法为每个参数独立调整学习率，提高训练效率和稳定性：

- **AdaGrad**：累计历史梯度的平方和，学习率随训练递减
- **RMSProp**：使用指数移动平均替代累加，避免学习率过早衰减
- **Adam**：结合动量和自适应学习率，是目前最常用的优化器

**Adam 更新公式：**

$$ m_t = \beta_1 \cdot m_{t-1} + (1 - \beta_1) \cdot \nabla_W L $$
$$ v_t = \beta_2 \cdot v_{t-1} + (1 - \beta_2) \cdot (\nabla_W L)^2 $$
$$ \hat{m}_t = \frac{m_t}{1 - \beta_1^t} $$
$$ \hat{v}_t = \frac{v_t}{1 - \beta_2^t} $$
$$ W \leftarrow W - \eta \cdot \frac{\hat{m}_t}{\sqrt{\hat{v}_t} + \epsilon} $$

其中 $\beta_1$（通常 0.9）和 $\beta_2$（通常 0.999）是衰减率，$\epsilon$（如 $10^{-8}$）防止除零。

### 8. 小批量梯度下降 (Mini-batch Gradient Descent)

将训练数据分成小批量（batches），每次使用一个小批量的数据来计算梯度并更新参数。这种方法结合了批量梯度下降的**稳定性**和随机梯度下降的**效率**，是实际训练中最常用的方法。

典型 batch size：32、64、128、256（受 GPU 显存限制）。

### 9. 学习率衰减 (Learning Rate Decay)

在训练过程中逐渐降低学习率，帮助模型在训练后期更精细地收敛，避免在最优解附近震荡。常见衰减策略：

- **阶梯衰减 (Step Decay)**：每隔一定 epoch 将学习率乘以一个因子（如 0.1）
- **指数衰减 (Exponential Decay)**：$\eta = \eta_0 \cdot e^{-k \cdot t}$
- **时间衰减 (Time Decay)**：$\eta = \frac{\eta_0}{1 + k \cdot t}$
- **余弦衰减 (Cosine Decay)**：$\eta = \eta_{\min} + \frac{1}{2}(\eta_0 - \eta_{\min})(1 + \cos(\frac{t}{T}\pi))$

### 10. 早停 (Early Stopping)

在训练过程中监控模型在验证集上的性能，如果验证性能在连续若干轮（patience）内没有提升，则提前停止训练。这种方法可以有效**防止过拟合**，并且节省训练时间。

### 11. 正则化 (Regularization)

通过在损失函数中添加正则化项来防止过拟合：

- **L1 正则化 (Lasso)**：$R(W) = \lambda \sum |W_{ij}|$ — 产生稀疏权重，有助于特征选择
- **L2 正则化 (Ridge / Weight Decay)**：$R(W) = \lambda \sum W_{ij}^2$ — 惩罚大权重，使权重分布更均匀
- **Dropout**：训练时随机丢弃一部分神经元，相当于隐式集成
- **数据增强 (Data Augmentation)**：对训练数据做随机变换（翻转、裁剪、颜色抖动等），是最有效的正则化手段之一

### 12. 批量归一化 (Batch Normalization)

在每个小批量中对每一层的激活值进行归一化处理，使其均值为 0、方差为 1，然后通过可学习的缩放（$\gamma$）和偏移（$\beta$）参数恢复表达能力：

$$ \hat{x} = \frac{x - \mu_{\text{batch}}}{\sqrt{\sigma^2_{\text{batch}} + \epsilon}} $$
$$ y = \gamma \hat{x} + \beta $$

批量归一化能够：
- 加速训练收敛（允许使用更大的学习率）
- 减少对初始化的敏感性
- 起到一定的正则化效果

### 13. 超参数调优 (Hyperparameter Tuning)

通过系统地搜索不同的超参数组合，找到使模型在验证集上表现最好的设置。需要调优的常见超参数包括：学习率、正则化强度 $\lambda$、batch size、网络结构等。

- **网格搜索 (Grid Search)**：遍历所有预定义的超参数组合。在参数较少时可行，但维度高时计算量爆炸。
- **随机搜索 (Random Search)**：在超参数空间中随机采样组合。实践表明在高维空间中比网格搜索更高效（因为不是每个超参数都同等重要）。
- **贝叶斯优化**：利用之前试验的结果来指导后续搜索，更加智能。

> **思考：超参数 $\Delta$ 和 $\lambda$ 该如何设置？**
> 通常我们通过交叉验证来选择这些超参数的值。在训练集上训练模型，并在验证集上评估性能，选择使得验证集性能最好的超参数组合。对于 $\Delta$，可以尝试不同的值（如 0.5、1.0、2.0）；对于 $\lambda$，通常在 log 尺度上搜索（如 $10^{-4}, 10^{-3}, 10^{-2}, 10^{-1}, 1$）。实践中 $\Delta$ 通常固定为 1，重点调 $\lambda$ 和学习率。
